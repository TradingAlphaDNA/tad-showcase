# 标准 CSV 导入——TAD 1.1.0-alpha.2

[English](standard-import.en.md) · [中英文字段指南及下载](../standard-import/index.html)

券商数据在你的 Mac 本机导入、处理及保存；TAD 的“上传”提交到本机应用，不是 TAD 云端。源码保持私有；产品仍在开发，计划采用 shareware 模式。

## 先试合成案例

在**全新独立**测试环境，选择创建账户 → Standard CSV，导入完整流水示例。核对账户引用 sample-account、来源券商 sample_broker、起点收盘日2026-01-01、现金1000、期初证券为空、流水截至2026-01-03。确认此合成案例的完整起点与交易后，明确应用。随后通过上传文件／更新账户，把完整持仓示例关联到该已有账户，核对并明确应用。当前快照不是期初余额。

预期：2美元买10股、3美元卖4股，剩6股、剩余成本12、已实现毛收益4；快照价3，对应市值18、浮盈6。CASH992是余额观察，不创造入金或收益。费用按已有来源口径保留，不因此证明完整。重复同一流水不应产生第二笔收益；当前持仓／报价使用保存日期，与已实现期间筛选不同。

## 将未支持券商转换为标准 CSV

1. 原件保持不变，填写稳定的真实券商键及账户引用；每份CSV仅含一个券商／账户／币种。每行成交是一笔真实执行，不把订单汇总拆成编造的成交。
2. 按指南映射明确事实；重复导出保留真实成交编号，或原件哈希／文档与行定位。不得编造日期、费用、0、成本、终止金额、到期／指派／行权记录或完整性。
3. net_cash 为含费用的有符号实际现金；gross_trade 为非负毛金额；未确定用 unqualified。remaining_total 成本带方向（空头负），average_unit 为非负单位成本；建账表单另填总成本绝对值。持仓市值须与数量×价格×乘数一致，浮盈须与市值−有符号成本一致。
4. 核对账户、日期、已读／未解析行、部分覆盖及待核项。已归档只表示保存，待更新尚未采用；只有明确应用后进入分析。原生／标准来源不能静默混用，不要为同一历史再建一个账户。
5. 真实资料测试与合成练习使用不同新环境。Setup不会升级已有安装，应保留原环境并选择新目录。见[真实数据上手](personal-data.zh.md)。

AI转换可选，在TAD外进行；优先使用本地工具。把原件发给云端AI是用户另行选择的数据传输，TAD不会代传。应用前逐行核对AI映射；TAD验证结构及一致性，不能证明AI忠实读取原件。

## 范围与待核

仅USD股票及乘数100的标准美股期权；不支持调整／非标准交割、换汇、期货、加密资产。估值持仓行需成本／口径、价格、市值、浮盈亏和报价日；缺失保持待核，不补0。部分快照缺证券不代表平仓；只采用一次账户book_cash余额，购买力／NAV／TOTAL不是现金。哈希和完整性旗标是映射声明，不代表独立核验原件或完整历史。只有终止数量、没有金额时不能推造盈亏；冲突记录及不明重叠需核对，未知身份不能猜测。已有历史期初／入账现金资格问题仍在支持矩阵公开说明。

[反馈](https://github.com/TradingAlphaDNA/tad-showcase/issues/new?template=technical-preview.yml)应脱敏；不要公开真实交易行、原件、备份、密钥或私人日志。
